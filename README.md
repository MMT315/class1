# آرشیو کلاس‌ها

یک صفحه‌ی تک‌فایلی برای شناسایی و پخش ویدیوهای آموزشی `class_1.mp4` تا `class_70.mp4`.

## ساختار پوشه

```text
archive-classes/
├── index.html
├── README.md
└── videos/
    ├── class_1.mp4
    ├── class_2.mp4
    └── ...
```

## اجرا

به دلیل محدودیت مرورگرها، درخواست‌های `HEAD` برای بررسی وجود فایل‌ها ممکن است روی آدرس `file://` مسدود شوند. پوشه را از طریق یک static server ساده اجرا کنید.

### روش Python

1. Python را نصب داشته باشید.
2. ترمینال را در همین پوشه (کنار `index.html`) باز کنید.
3. اجرا کنید:

```bash
python -m http.server 8000
```

4. در مرورگر آدرس `http://localhost:8000` را باز کنید.

همچنین می‌توانید فایل‌ها را روی GitHub Pages یا هر سرویس میزبانی static قرار دهید.

## نام‌گذاری و رفتار

- فایل‌ها باید دقیقاً در پوشه‌ی `videos/` باشند و نامشان به صورت `class_N.mp4` باشد.
- فقط فایل‌هایی که سرور برای آن‌ها پاسخ `HEAD` با وضعیت `200` بدهد نمایش داده می‌شوند.
- پس از بالاترین شماره‌ی موجود، حداکثر یک کارت قفل‌شده نمایش داده می‌شود؛ اگر شماره‌ی ۷۰ موجود باشد کارت قفل اضافه نمی‌شود.
- اگر هیچ ویدیویی پیدا نشود، پیام راهنما نمایش داده می‌شود.
- دکمه‌ی هدر بین تم تاریک و روشن جابه‌جا می‌شود و انتخاب در مرورگر ذخیره می‌شود.

## نکته

برای اجرای این پروژه به بیلد، کتابخانه JavaScript یا سرور اختصاصی نیاز ندارید؛ تنها یک static server کافی است. فونت Vazirmatn از Google Fonts بارگیری می‌شود و در صورت نبود اتصال اینترنت، فونت جایگزین مرورگر استفاده خواهد شد.
